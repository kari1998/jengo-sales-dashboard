# Jengo Supplies: Sales and Profit Dashboard

An Excel dashboard and written review of sales and profit for Jengo Supplies, a retailer with five branches (Nairobi, Mombasa, Kisumu, Nakuru, Eldoret), covering January to October 2026.

![Dashboard](images/dashboard.png)

## Key findings
- Revenue was about KES 4.41 million and profit about KES 1.22 million (28% margin).
- From July, monthly profit fell by about a third while revenue fell about 15%.
- Electronics discounts rose from about 1% to about 21%, which cut Electronics margin from 34.5% to 20.0%.
- Kisumu's sales fell 59% from July across every category and both sales reps. The data cannot show why.

## What is in this repo
- data/ : the cleaned dataset (3,254 orders, 2,927 completed sales)
- dashboard/ : the Excel dashboard with PivotTables, charts and slicers
- report/ : the full written review, including the cleaning log and assumptions

## How to use the dashboard
Open the workbook, go to the Dashboard sheet and click a branch or category in the slicers. The KPI cards and charts update together.

## Tools
Excel (PivotTables, PivotCharts, slicers), data cleaning, python.
